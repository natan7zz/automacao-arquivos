## 📄 Sobre o projeto

O **Automação de Arquivos** (Sistema Busca PDFs) é um aplicativo desktop para Windows que automatiza a **busca e a organização de arquivos PDF**, eliminando tarefas manuais e repetitivas.

Leve, rápido e com interface simples, roda direto no computador, sem instalação complicada.

## ✨ Funcionalidades

- 🔍 Busca de arquivos PDF
- 🗂️ Organização automática de arquivos
- ⚙️ Tela de configurações
- ⚡ Execução rápida e leve (Rust + Tauri)
- 🖥️ Interface moderna com barra lateral

## 🚀 Como usar

1. Acesse a aba [**Releases**](../../releases) deste repositório.
2. Baixe o arquivo `automacao-arquivos-corrigido.exe`.
3. Execute o programa no Windows.

> ⚠️ O Windows pode exibir um aviso de "aplicativo não reconhecido". Clique em **Mais informações → Executar assim mesmo**.
